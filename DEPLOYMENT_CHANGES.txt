2. BACKEND — core/settings.py
----------------------------------------------------------------

PURANA:
  CHANNEL_LAYERS = {
      'default': {
          'BACKEND': 'channels.layers.InMemoryChannelLayer',
      },
  }

NAYA (production me Redis use karo WebSocket ke liye):
  CHANNEL_LAYERS = {
      'default': {
          'BACKEND': 'channels_redis.core.RedisChannelLayer',
          'CONFIG': { 'hosts': [('127.0.0.1', 6379)] },
      },
  }
  NOTE: pip install channels-redis  aur  apt install redis-server

PURANA:
  STATIC_URL = 'static/'
  (STATIC_ROOT missing hai)

NAYA (add karo settings.py me):
  STATIC_ROOT = BASE_DIR / 'staticfiles'
  STATIC_URL = '/static/'
  NOTE: python manage.py collectstatic command chalana hoga deploy ke time

NAYA:

6. NGINX CONFIG (agar Nginx use kar rahe ho)
----------------------------------------------------------------

Frontend serve karne ke liye:
  server {
      listen 80;
      server_name teople.com www.teople.com;
      root /var/www/teople/dist;
      index index.html;
      location / {
          try_files $uri $uri/ /index.html;   ← React routing ke liye zaroori
      }
  }

Backend proxy ke liye:
  server {
      listen 80;
      server_name api.teople.com;
      location / {
          proxy_pass http://127.0.0.1:8000;
          proxy_set_header Host $host;
          proxy_set_header X-Real-IP $remote_addr;
      }
      location /ws/ {
          proxy_pass http://127.0.0.1:8000;
          proxy_http_version 1.1;
          proxy_set_header Upgrade $http_upgrade;
          proxy_set_header Connection "upgrade";
      }
  }
